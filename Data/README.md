# Data Sources

The modeling dataset was constructed from multiple NFL data sources covering
the 2016–2025 seasons.

Sources include:

- nflverse (check index for full available data: https://nflreadr.nflverse.com/reference/index.html )
- ProFootballFocus
- ESPN/ESPN Fantasy
- DraftSharks.com
- teamrankings.com
- FootballReference

Raw datasets are not included in this repository due to file size and
redistribution considerations. The full modeling Dataset will be included.

Data preparation and feature engineering are documented in the `/code`
directory.
